# Experiment 3 - Stemming and Lemmatization

## Aim
To implement stemming and lemmatization using NLTK.

## Description
Stemming reduces words by chopping prefixes or suffixes, while lemmatization converts words into meaningful dictionary base forms.

## Concepts Used
- Porter Stemmer
- WordNet Lemmatizer
- Root Word Extraction

## Technologies Used
- Python
- NLTK
- Google Colab

## Output
Words were successfully reduced into their root/base forms using stemming and lemmatization.
